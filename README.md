엑셀과 VBA로 직접 구현한 경영 최적화 모형 21종과 몬테카를로 시뮬레이션 모형 23종을 정리한 목록입니다.

**공개 주소** — https://jihongparker.github.io/quant-lab/

환율선물, 상품선물 헤지, 통화옵션 헤지, 델타헤지

## 구성

정적 단일 페이지입니다. 외부 의존성이 없습니다. 항목을 열면 세 층이 나옵니다.

1. **동적 모형** — 44개 모형 전부를 자바스크립트로 다시 구현한 인터랙티브 패널.
   슬라이더로 모수를 바꾸고, 몬테카를로를 브라우저에서 다시 돌리고, 델타헤지를
   주 단위로 재생합니다.
2. **시트 발췌 캐러셀** — 원본 통합문서 106개 시트의 격자 발췌. 값·굵기·채움을
   보존했고, 밑줄 셀에 마우스를 올리면 실제 엑셀 수식이 수식 바에 표시됩니다.
3. **절차·수치·해석** — 풀이 절차, 입력값, 엑셀 기록 결과값, 결과 해석.

```
index.html       페이지 골격·캐러셀·시트 렌더러
data.js          44개 모형의 절차·입력값·결과·해석
grids.js         통합문서 106개 시트 발췌 (값 + 수식 + 스타일)
engine-data.js   동적 패널용 원자료 시리즈 (회귀 쌍·수익률·가격 등)
engines.js       공용 캔버스 차트 라이브러리 + 모형별 동적 엔진 44종
README.md
```

난수를 쓰는 동적 패널은 돌릴 때마다 값이 달라지므로 표의 엑셀 기록값과 수치가
다를 수 있으며, 모수를 단순화한 패널은 그 사실을 패널 안에 명시했습니다.
